Located at Bahar Unnao Gate, Near Naogoji Kua, Jhansi, Uttar Pradesh - 284002.

## 📁 Repository Structure
- `index.html` - Complete Gauri Greens layout, structure, and responsive components
- `style.css` - Gauri Greens theme variables, pill buttons, heading dividers, custom scrollbars, and interactive cards
- `script.js` - WhatsApp inquiry routing, FAQ accordions, 5-category photo filters, and interactive full-screen Lightbox modal
